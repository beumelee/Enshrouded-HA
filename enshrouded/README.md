# Enshrouded Dedicated Server

Dedizierter [Enshrouded](https://store.steampowered.com/app/1203620/Enshrouded/)-Server
als Home-Assistant-App (nur x86-64).

- Freunde treten über das Internet bei (Portfreigabe UDP 15637)
- Automatische Server-Updates, sobald niemand online ist
- RAM-Wächter mit einstellbarem Limit (Standard 10 GB)
- Spielstände im Home-Assistant-Backup

Die vollständige Anleitung steht im Reiter **Dokumentation** der App.
